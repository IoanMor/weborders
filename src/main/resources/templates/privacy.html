Политика обработки персональных данных

1. Общие положения

Настоящая политика описывает порядок обработки персональных данных, предоставляемых пользователем при заполнении формы на сайте.

2. Какие данные собираются

Сайт собирает только следующие данные:

  • Номер телефона

Дополнительно пользователь может указать имя и описание задачи.

3. Цель обработки данных

Данные используются исключительно для:

  • связи с пользователем;
  • обсуждения и выполнения заявки;
  • уточнения деталей запроса.

4. Передача третьим лицам

Персональные данные не передаются третьим лицам, не продаются и не используются в рекламных целях.

5. Хранение данных

Данные хранятся только на время обработки заявки и используются исключительно для связи с клиентом.

6. Согласие пользователя

Отправляя форму на сайте, пользователь подтверждает согласие на обработку персональных данных в рамках данной политики.
